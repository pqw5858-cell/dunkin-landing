# DUNKIN' 랜딩 페이지 (포트폴리오)

던킨 제품 4종 소개, 브랜드 이야기, 근처 매장 찾기를 담은 원페이지 랜딩 페이지입니다.

> 개인 포트폴리오 목적의 비상업적 사이트이며, 던킨(DUNKIN')의 공식 사이트가 아닙니다.
> 사용된 브랜드명, 로고, 제품 이미지의 권리는 각 권리자에게 있습니다.

## 구성
- **PRODUCTS** — 제품 4종 전환 모션 (배경·재료·도넛 낙하, 텍스트 롤링), 판매 매장 / 영양 정보 모달
- **BRAND** — 히스토리, 도넛 만드는 과정, 고객과의 약속, 위생점검 결과
- **STORE** — 카카오맵 API로 근처 던킨 매장 검색

## 기술
HTML / CSS / JavaScript (라이브러리 없음, Web Animations API), Kakao Maps JavaScript API

## 실행
로컬 서버(VS Code Live Server 등)로 `index.html`을 열어주세요.
지도는 카카오 개발자 콘솔에 등록된 도메인에서만 표시됩니다.
